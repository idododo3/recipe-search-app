# Adapters

שכבת ה-adapters מפרידה בין הליבה לבין העולם החיצון. ב-MVP קיים adapter אחד בלבד:

## `github.js`

פועל ב-**dry run בלבד**: מחזיר תיאור מדויק של הפעולה שהייתה מתבצעת, רושם אותה ל-audit,
ולא מבצע שום קריאת רשת. נתיב `live` קיים כהצהרה אך זורק `LiveModeNotImplementedError` —
מעבר אליו דורש מימוש מכוון, לא רק שינוי משתנה סביבה.

## ממשקים עתידיים

הליבה לא יודעת דבר על ערוץ הקלט. כדי לחבר בעתיד ערוץ כלשהו (למשל מערכת הודעות
או סוכן קוד חיצוני), יש לממש:

* **ערוץ קלט** — קורא ל-`AgentBridge.submit()` עם `{ title, description, repo }`,
  ומציג ל-מאשר את `pendingApproval.requestId` כדי לקרוא ל-`approve`/`deny`.
* **Runner** — מחלקה שיורשת מ-`src/runners/runner.js` ומממשת `plan()` ו-`execute()`.

> אין כאן אינטגרציה רשמית לשום שירות צד-שלישי. לא קיים API רשמי של Instinct,
> של WhatsApp או של Claude Code שמשמש כאן, ואין להציג את הקוד הזה כאינטגרציה כזו.
