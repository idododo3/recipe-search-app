# חידת הזאב, הכבש והכרוב 🐺🐑🥬

משחק דפדפן בעברית (RTL) של חידת המעבר הקלאסית: חקלאי צריך להעביר זאב, כבש וכרוב
מגדה אחת של נהר לשנייה, בסירה שיש בה מקום לנוסע אחד בלבד.

המשחק כתוב ב-HTML, CSS ו-JavaScript בלבד — בלי ספריות, בלי שלב בנייה ובלי קבצי
מדיה חיצוניים. כל הגרפיקה מצוירת בזמן אמת על `<canvas>`, וכל הצלילים מסונתזים
ב-Web Audio API.

## הפעלה

פותחים את `index.html` בדפדפן. זהו.

לשרת מקומי (לא חובה):

```
python3 -m http.server 8000
```

ואז נכנסים אל <http://localhost:8000>.

## איך משחקים

* לחיצה על דמות מעלה אותה לסירה, לחיצה נוספת מורידה אותה.
* כפתור **להפליג!** מעביר את הסירה לגדה השנייה. אפשר גם להפליג לבד.
* אם הזאב והכבש נשארים לבד בגדה — הכבש נאכל. אם הכבש והכרוב נשארים לבד — הכרוב נאכל.
* הפתרון האופטימלי הוא **7 הפלגות**.

מקשי קיצור: <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> בחירת נוסע, <kbd>רווח</kbd>
הפלגה, <kbd>M</kbd> מוזיקה, <kbd>S</kbd> אפקטים, <kbd>H</kbd> חוקים,
<kbd>L</kbd> לוח שיאים, <kbd>R</kbd> התחלה מחדש.

## מה יש במשחק

| דרישה | מימוש |
| --- | --- |
| גרפיקה | סצנת שקיעה מצוירת בקנבס: שמיים מדורגים, הרים, יער רחוק, מים עם גלים, ניצוצות והשתקפויות, דמויות וקטוריות מונפשות, חלקיקים וקונפטי |
| מוזיקה | פסקול לולאתי מסונתז (רה מינור, פד + בס + ליד + כלי הקשה) ואפקטי קול לכל פעולה, עם כפתורי השתקה נפרדים |
| נוחות משתמש | ממשק עברי RTL, רמזים מתחלפים, הדגשת דמות בריחוף, הודעות מצב, מקשי קיצור, פריסה מותאמת למסכי מובייל |
| ניקוד מצטבר | ניקוד נצבר לשחקן לפי שם ונשמר בין ביקורים |
| זמן | שעון עצר לכל סיבוב, שמשפיע על הניקוד |
| שמירת שם ותוצאה | לוח שיאים מקומי עם שם השחקן, ניקוד, זמן ומספר הפלגות |

### חישוב הניקוד

```
600 בסיס
+ עד 400 על יעילות (הפחתה של 70 לכל הפלגה מעבר ל-7)
+ עד 300 על מהירות (הפחתה של 8 לכל שנייה מעבר ל-25)
+ 200 בונוס פתרון מושלם
+ 25 לכל שלב שהושלם קודם
- 80 על כל טעות שגרמה לאכילה
```

## מבנה הקבצים

```
index.html      שלד הדף, ה-HUD והמסכים
css/styles.css  עיצוב הממשק
js/audio.js     מנוע המוזיקה והאפקטים (Web Audio)
js/art.js       ציור וקטורי של הדמויות, הסירה והצמחייה
js/scene.js     הבמה: רקע, מים, מצלמה, חלקיקים ולולאת הציור
js/game.js      חוקי החידה, ניקוד, זמן, שמירה וקישור הממשק
```

## הערות טכניות

* שכבות הרקע הסטטיות נצרבות פעם אחת ל-canvas לא-נראה, כדי לשמור על קצב פריימים גבוה.
* התוצאות נשמרות ב-`localStorage` תחת המפתח `wolfRiver.v1`. אם האחסון חסום, המשחק
  פשוט ממשיך לפעול בלי שמירה.
* ההפלגה היא רצף קולנועי: המצלמה נצמדת לסירה, מתקרבת ומתנדנדת יחד איתה. זהו אפקט
  ויזואלי בלבד — אין בו שליטה או אתגר נוסף.
